ANASWARA KC PORTFOLIO - FINAL STATIC WEBSITE

HOW TO DEPLOY
1. Extract this ZIP.
2. Upload/replace all files and the assets folder in your existing GitHub repository. Keep the folder structure exactly as provided.
3. Commit changes. Vercel should deploy automatically.

IMPORTANT SETTINGS
- Open site-config.js to add the WhatsApp number in international format, digits only (example format: 919876543210). The WhatsApp floating button is visible now and opens direct chat once this is configured.
- Update the email and social profile URLs in site-config.js if needed.
- The portfolio chat widget answers common questions from the content on this site. It is a local portfolio FAQ assistant, not a connected generative AI model. A secure server-side AI API integration is required for live AI-generated replies. Do not place an API key in browser JavaScript.

IMAGE FILES
All project screenshots and poster designs from the supplied ZIP are retained in assets/. The six additional photos supplied for achievements/journey have also been added.

NOTES
- The intro welcome screen runs on each page load and includes a Skip intro control.
- Project gallery filters and Previous/Next controls are interactive.
- Service cards scroll horizontally with arrow controls.
- Achievement photos open in a larger lightbox when clicked.
- The site is responsive for mobile and desktop.
